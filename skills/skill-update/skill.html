요약

기존 shared skill의 수정, rename, split, deprecate, archive를 원본 delta와 repo 표면 정합성 기준으로 처리한다.

  • 사용할 때기존 shared skill의 수정, rename, split, deprecate, archive를 원본 delta와 repo 표면 정합성 기준으로 처리한다.
  • 주요 입력변경 요청, upstream/source registry, SKILL.md, agents/openai.yaml, validator, snippet, history.
  • 주요 출력정렬된 skill package 변경, source decision, validator/eval/docs/history 갱신.
  • 먼저 판단plugin update list나 dependency sweep은 별도 lane으로 다루고, adopt/adapt/reject/defer를 기록한다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.
