skill-update

기존 shared skill을 고칠 때 원본 출처, local package, 검증 증거를 한 번에 맞추는 업데이트 전용 스킬입니다.

에이전트 원본SKILL.md
사람용 가이드skill.html
진입 문서docs/update-source-registry.md를 먼저 읽고 source family를 고릅니다.

사용 판단 매트릭스

요청의 성격에 따라 업데이트 lane과 멈춤 조건을 먼저 나눕니다.

사용

기존 shared skill을 업데이트, 수정, 개선, 유지보수, rename, split, deprecate, archive할 때 사용합니다.

함께 사용

원본 확인이 필요한 경우 web-research, HTML 변경이 있으면 skill-to-html, 문서 drift는 sync-docs와 연결합니다.

분리

plugin package, MCP config, submodule bump는 사용자가 plugin update를 명시했을 때만 plugin update lane에서 다룹니다.

묻기

trigger 의미 변경, behavior 제거, rename, split, archive, repo-wide preference 변경, source-of-truth 충돌은 먼저 확인합니다.

전체 실행 흐름

source registry에서 시작해 최소 변경과 검증으로 끝냅니다.

1. source family 선택docs/update-source-registry.md를 읽고 repo-owned skill, vendored plugin, workflow provenance primitive 중 관련 군을 고릅니다.
2. provenance preflight대상 skill, references, history, snippets, agents/openai.yaml, git history에서 원본과 fork 흔적을 찾습니다.
3. 원본 delta 분류확인한 변경 후보를 adopt, adapt, reject, defer로 나누고 local package에 필요한 것만 반영합니다.
4. 검증과 증거변경 범위에 맞는 validator, 한국어 Markdown 검사, HTML 검사, browser rendering check 결과를 보고합니다.

업데이트 Lane

같은 skill-update라도 요청 범위에 따라 읽을 source와 금지선이 달라집니다.

Local skill package 일반적인 shared skill 수정 경로입니다.
  • SKILL.md를 concise하게 유지합니다.
  • 긴 기준은 references/로 분리합니다.
  • material change면 skill.html과 history를 맞춥니다.
Plugin update lane 사용자가 plugin update를 명시했을 때만 엽니다.
  • .gitmodules를 canonical source로 봅니다.
  • release note, manifest, bundled skill 경로를 확인합니다.
  • MCP config와 submodule bump를 incidental하게 하지 않습니다.
Dependency update sweep repo-wide 외부 dependency 갱신 요청일 때만 실행합니다.
  • vendored plugin 전체를 점검합니다.
  • repo-owned plugin과 workflow primitive map을 함께 봅니다.
  • source ledger와 validator drift를 남깁니다.

금지와 허용

업데이트 스킬은 source-of-truth를 맞추지만 요청 범위 밖 자동화를 하지 않습니다.

허용

대상 skill package, 관련 snippets, docs, history, validators를 하나의 package로 맞춥니다.

기록

source URL, checked date, upstream version 또는 commit, local 채택 판단을 ledger로 남깁니다.

보류

plugin package, MCP config, submodule 자체는 incidental하게 업데이트하지 않습니다.

차단

승인 없는 commit, push, install, 전역 등록, destructive command, 비밀값 포함 파일 변경은 멈춥니다.

완료 보고 조각

최종 답변에는 변경 범위와 증거만 짧게 남깁니다.

변경: skills/skill-update/skill.html
근거: SKILL.md의 source registry, provenance preflight, plugin update lane, dependency sweep 규칙을 반영했습니다.
검증: node scripts/validate-skill-html.ts .
시각 확인: PC desktop 기준으로 표 폭, SVG arrow endpoint, overflow, text overlap을 확인했습니다.
