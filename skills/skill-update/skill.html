skill-update

기존 shared skill을 업데이트, 수정, 개선, 유지보수, rename, split, deprecate, archive할 때 범위와 원본 근거를 먼저 고정하고, 스킬 문서와 검증 산출물을 함께 맞추는 작업 가이드다.

요약

이 스킬은 사용자가 요청한 behavior change에서 시작한다. 기존에 유용한 동작은 요청 없이 제거하지 않고, 원본 또는 upstream이 있는 경우 provenance preflight와 source ledger를 먼저 확인한다.

호출 조건

스킬의 trigger, workflow, validator, snippet, provenance, lifecycle 상태를 바꾸는 요청.

핵심 출력

수정된 skill package, 동기화된 보조 파일, 실행한 validator, 남은 위험과 보류 항목.

원본 우선순위

docs/update-source-registry.md, local provenance, 필요 시 web-research.

범위 제한

plugin package, MCP config, submodule은 사용자가 plugin update를 명시했을 때만 다룬다.

사용 판단

요청 유형 처리 방식 후속 동기화
trigger 또는 description SKILL.md, snippet, README/AGENTS, metadata를 함께 점검한다. skill.html, catalog, history/skills.md
workflow 또는 rules 짧은 trigger 문서는 유지하고 긴 설명은 references/로 분리한다. validator, HTML, history
validator 또는 script 검증 명령과 README command drift를 함께 확인한다. 관련 validator 실행, 필요 시 history
rename, split, archive 경로 전체, catalog, lifecycle 기준을 연결해 갱신한다. show-skills HTML catalog, lifecycle, history
dependency update sweep .gitmodules, repo-owned plugin, workflow primitive lane, usage map을 점검한다. registry source ledger, plugin catalog, validators

중요한 기준

  1. 사용자가 의도한 behavior change에서 시작하고, 대상 skill과 결과물을 먼저 확인한다.
  2. 기존 유용한 behavior는 요청 없이 제거하지 않는다.
  3. SKILL.md는 concise하고 trigger-focused로 유지하며 긴 예시와 취향은 references/로 옮긴다.
  4. material change가 있으면 markdown-to-html로 adjacent skill.html도 갱신한다.
  5. 원본이 있는 스킬은 docs/update-source-registry.md와 필요한 web verification으로 provenance를 남긴다.

원본 전체를 복사하지 않는다. 변경 후보는 adopt, adapt, reject, defer로 분류한 뒤 이 repo의 cross-agent 계약에 맞는 delta만 반영한다.

필수 문구 HTML에서 확인할 의미
원본 delta 분류 원본 변경 후보를 무조건 복사하지 않고 adopt, adapt, reject, defer로 판단한다.
레지스트리 docs/update-source-registry.md를 source URL, checked date, upstream version/commit의 기준으로 읽는다.
Plugin update list .gitmodules에서 파생된 사람이 읽는 plugin update checklist로 다룬다.
Dependency update sweep 명시 요청일 때 vendored plugin, repo-owned plugin, workflow primitive lane, usage map을 함께 점검한다.
source package, primitive name, adopted role workflow primitive provenance를 기록할 때 원본 package, primitive 이름, local 채택 역할을 분리한다.
SVG arrow endpoint PC viewport 확인에서 SVG 화살표 끝점, 표 폭, overflow, text overlap을 함께 본다.

파일 관계도

스킬 변경은 기준 원문 하나만 고치는 작업이 아니다. 실행 규칙, 사용자용 HTML, 프로젝트 snippet, catalog, history, validator가 같은 이름과 같은 계약을 말해야 한다.

파일 역할 drift 확인
SKILL.md agent가 따르는 기준 원문 trigger, 금지 경계, workflow가 요청과 맞는지 본다.
skill.html 사람이 빠르게 읽는 adjacent guide markdown-to-html 기준과 local link를 확인한다.
project-snippets/*.md target project에 붙이는 호출 문구 공개 slug, path, override 문구가 현재 skill과 같은지 본다.
docs/update-source-registry.md 원본 출처와 업데이트 lane의 기준 source URL, checked date, plugin lane이 흩어지지 않았는지 본다.
history/skills.md 현재 레지스트리와 생명주기 기록 Current Registry가 삭제되거나 rename된 skill을 살아 있는 것처럼 말하지 않는지 본다.
scripts/validate-*.ts 계약 회귀를 막는 검증기 파일명, 필수 문구, repo path가 실제 tree와 맞는지 본다.

작업 흐름

1. 요청 읽기

사용자 의도, 대상 skill, repo 경계를 확인한다.

2. 원본 확인

SKILL.md, registry, local provenance, 필요한 references를 읽는다.

3. 변경 분류

scope, source family, plugin lane 여부, dependency sweep 여부를 고른다.

4. 최소 수정

요청 범위 안에서 문서, HTML, validator, snippet을 맞춘다.

5. 증거 보고

검증 명령, 미해결 위험, 보류한 원본 변경을 남긴다.

보안 경계

허용

  • 요청된 skill package 안의 SKILL.md, references/, validator, skill.html 정합성 갱신.
  • 원본 조사 결과를 docs/update-source-registry.md source ledger로 남기는 작업.
  • skill add/remove/rename/archive/restore 뒤 show-skills HTML catalog를 재생성하는 작업.
  • 검증 실패가 작업 범위와 직접 연결될 때 최소 수정으로 해결하는 작업.

금지

  • 사용자 요청 없이 기존 behavior를 제거하거나 default agent behavior로 대체하는 일.
  • plugin package, MCP config, submodule을 incidental하게 업데이트하는 일.
  • 전역 skill 설치, symlink, auto-register, publish, destructive command 실행.
  • 비밀값, 개인 데이터, live credential을 문서나 history에 남기는 일.

질문해야 하는 경우

사용자 요청이 repo-local preference를 바꾸는지, upstream source 자체를 바꾸는지, 특정 프로젝트 override인지 구분되지 않으면 수정 전에 범위를 좁힌다.

파일과 검증

변경 범위가 넓어질수록 문서, HTML, validator, registry, history가 함께 움직인다. 아래 항목은 skill-update가 material change를 끝냈다고 말하기 전에 확인하는 대표 경로와 명령이다.

  • SKILL.md - 기준 원문
  • skill.html - adjacent human guide
  • docs/update-source-registry.md - source ledger
  • history/skills.md - lifecycle event
  • project-snippets/skill-update.md - project setup snippet
  • scripts/validate-skill-update.ts - skill-specific validator

정적 HTML node scripts/validate-skill-html.ts . 외부 asset, raw HTML 위험, local link, 구조 규칙
스킬 업데이트 전용 node skills/skill-update/scripts/validate-skill-update.ts skills/skill-update registry, provenance, workflow contract
