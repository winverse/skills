사용 판단 매트릭스

언제 쓰고, 언제 다른 스킬로 넘길지 먼저 판단합니다.

사용

현재 repo의 스킬을 보고, 나열하고, 요약하고, 비교하거나 작업에 맞는 스킬을 고를 때 사용한다.

결합

문서 drift는 sync-docs, 브라우저 증거는 browser-qa, 커밋은 atomic-committer처럼 전담 스킬과 연결합니다.

건너뜀

요청이 이 스킬의 호출 조건과 맞지 않거나 더 구체적인 스킬이 있으면 그 스킬을 우선합니다.

확인

비밀값, 파괴적 작업, 외부 쓰기, 전역 설치가 얽히면 먼저 범위와 승인 조건을 확인합니다.

금지와 허용

스킬은 요청된 작업을 돕는 도구이며, 범위 밖 자동화는 하지 않습니다.

허용

관련 파일을 읽고, 요청된 범위 안에서 가장 작은 유효 변경을 수행합니다.

보고

변경 파일, 검증 명령, 브라우저 확인 여부를 최종 답변에 남깁니다.

보류

요청과 무관한 refactor, 문서 확장, 전역 설치는 하지 않습니다.

차단

비밀값 노출, destructive command, 승인 없는 commit/push/deploy는 멈춥니다.

프로젝트 연결 조각

프로젝트 instruction에는 스킬 링크와 최소 완료 조건만 둡니다.

Use $show-skills at skills/show-skills/SKILL.md when the task matches this skill.
Keep visible explanations Korean-first, preserve exact identifiers, and report validation evidence.
Validate with node scripts/validate-skill.ts skills/show-skills && node skills/show-skills/scripts/validate-show-skills.ts skills/show-skills && node scripts/validate-skill-html.ts ..
