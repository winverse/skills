transcript-polisher

텍스트 전사본, 강의 대본, 자막, 회의록, 긴 산문을 에이전트가 직접 읽고 문맥에 맞게 검토하거나 다듬을 때 사용한다. 코드 치환표, regex, 일괄 문자열 치환으로 해결하지 않고 어색한 STT 용어, 깨진 문장, 문단 흐름, 강의 흐름, 섹션 연결, 용어 일관성을 직접 판단해 수정한다. 사용자가 문단이나 구문 단위로 나누고 각 단위마다 서브 에이전트를 배정하라고 요청하거나, Claude Code의 `/goal`처럼 완료 조건을 두고 평가자가 충족 여부를 확인할 때까지 반복 검토 루프를 돌리라고 할 때 특히 사용한다.

요약

전사본, 강의 대본, 자막, 회의록, 긴 산문을 문맥에 맞게 직접 읽고 다듬는다.

  • 사용할 때전사본, 강의 대본, 자막, 회의록, 긴 산문을 문맥에 맞게 직접 읽고 다듬는다.
  • 주요 입력원문 transcript, 출력 구조, 보존해야 할 예시와 용어, polish 목표.
  • 주요 출력문단 흐름과 용어가 정리된 polish 결과, 보존된 source/output relative path, 완료 증거.
  • 먼저 판단regex나 일괄 치환으로 처리하지 않고, lecture examples와 awkward-output examples를 보존한다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.
