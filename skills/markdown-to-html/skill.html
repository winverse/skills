markdown-to-html

Markdown 문서의 heading, list, table, code fence, link 의미를 읽어 MarkdownHtmlModel로 줄이고, 신뢰된 템플릿으로 안전한 단일 HTML을 만든다.

스킬 HTML mode · Markdown parse · AST/IR · 한국어 우선 · 보안 경계 · 인터랙션 없음

요약

원문을 화면에 그대로 옮기지 않고 필요한 의미만 추려 짧은 HTML로 렌더링한다.

  • 입력SKILL.md와 필요한 참조 Markdown을 읽는다.
  • mode기본은 같은 폴더의 skill.html만 갱신하는 스킬 HTML mode다.
  • 모델문서 의미를 MarkdownHtmlModel에 넣는다.
  • 출력같은 폴더의 skill.html을 단일 파일로 갱신한다.
  • 차단raw HTML, event handler, 위험한 URL, 외부 script는 통과시키지 않는다.

사용 판단

Markdown 문서가 새로 생겼거나 기준이 바뀌었고, 사람이 설치 전후에 빠르게 볼 HTML이 필요할 때 사용한다. 단순 오탈자 수정이나 이미 최신인 HTML에는 쓰지 않는다.

중요한 기준

  • 구조 보존heading, list, table, code fence, link의 역할을 먼저 읽는다.
  • 중간 모델문단을 그대로 복사하지 않고 MarkdownHtmlModel로 줄인다.
  • 신뢰된 렌더링repo가 작성한 템플릿으로만 HTML을 만든다.
  • URL 제한http:, https:, mailto:, repo-local 상대 경로만 남긴다.
  • 한국어 우선화면에 보이는 일반 설명어는 한국어로 쓴다.
  • 읽기 전용버튼, script, animation, 보기 전환 없이 읽힌다.

작업 흐름

  1. 1mode 선택기본은 스킬 HTML mode이고, 일반 Markdown 문서 mode는 대상과 출력 위치가 명시됐을 때만 쓴다.
  2. 2구문 분석Markdown parser나 token stream으로 문서 구조를 읽는다.
  3. 3의미 추출목적, 입력, 출력, 기준, 흐름, 보안 경계만 남긴다.
  4. 4HTML 작성신뢰된 템플릿에 모델을 넣어 단일 HTML을 만든다.
  5. 5검증넘침, 겹침, 링크, 위험한 URL 속성, 외부 의존을 확인한다.

보안 경계

허용

항목 기준
Markdown 구조 heading, list, table, code fence, blockquote, link의 의미를 보존한다.
도표 원문에 실제 흐름, 관계, 계층이 있을 때만 만든다.

조건부 허용

항목 기준
raw HTML 꼭 필요할 때만 별도 parser로 읽고 allowlist sanitizer를 마지막 unsafe transform 이후에 적용한다.
URL 허용한 protocol과 repo-local 상대 경로만 남긴다.

금지

항목 기준
실행/외부 의존 <button>, inline JavaScript, event handler, javascript: link, vbscript: link, <iframe>, <object>, <embed>, 외부 CDN, 외부 script, 외부 image.
본문 자기해설 배치 의도, 색상 설명, 보기 방식 설명처럼 원문 의미가 아닌 문장을 넣지 않는다.
