markdown-to-html

Markdown 문서의 heading, list, table, code fence, link 의미를 읽고 MarkdownHtmlModel에 담아 script 없는 단일 HTML을 만든다.

Markdown parse · 스킬 HTML mode · 일반 Markdown 문서 mode · 한국어 우선 · 보안 경계 · 인터랙션 없음

요약

SKILL.md를 빠른 확인용 skill.html로 만들거나, 사용자가 명시한 Markdown 문서를 안전한 HTML 문서로 변환한다.

  • 입력SKILL.md와 필요한 참조 Markdown, 또는 사용자가 지정한 Markdown 문서.
  • mode기본은 인접한 skill.html만 갱신하는 스킬 HTML mode다.
  • 모델스킬 HTML mode는 요약 정보를 담고, 일반 Markdown 문서 mode는 heading tree, 표, 목록, code fence 같은 복잡한 구조를 담는다.
  • 출력신뢰된 템플릿으로 렌더링한 단일 HTML 파일.
  • 차단raw HTML, event handler, 위험한 URL, 외부 script, 외부 asset은 실행 가능한 형태로 통과시키지 않는다.

사용 판단

스킬이 생성, 설치, fork, 갱신되어 사람이 읽을 인접 HTML이 필요하면 사용한다. 일반 Markdown 문서 mode는 사용자가 입력과 출력 위치를 모두 명시했을 때만 사용한다.

중요한 기준

  • 의미 우선heading, list, table, code fence, blockquote, link의 역할을 먼저 읽는다.
  • 요약 범위스킬 HTML mode는 빠른 판단에 필요한 이름, 목적, 입출력, 기준, 흐름, 보안 경계, 검증만 남긴다.
  • 구조 보존일반 Markdown 문서 mode는 긴 문단, 깊은 heading, 표, 중첩 list, code fence 같은 원문 구조를 보존한다.
  • URL 제한http:, https:, mailto:, repo-local 상대 경로만 남긴다.
  • 읽기 전용<button>, inline JavaScript, animation, 보기 전환 없이 PC desktop에서 읽히게 둔다.

작업 흐름

  1. 1mode 선택이 repo의 기본은 SKILL.md에서 같은 폴더의 skill.html을 만드는 스킬 HTML mode다.
  2. 2구조 읽기Markdown parser나 token stream으로 문서의 블록과 링크 역할을 구분한다.
  3. 3모델 추출mode에 맞춰 MarkdownHtmlModel을 채우고, 일반 설명어는 한국어로 정리한다.
  4. 4HTML 작성원문 Markdown 단편과 최종 HTML을 분리하고, 신뢰된 템플릿으로 렌더링한다.
  5. 5검증overflow, text overlap, local link, 위험한 URL 속성, 외부 의존, 검증 명령을 확인한다.

보안 경계

허용

항목 기준
Markdown 구조 heading, list, table, code fence, blockquote, link의 의미를 보존한다.
단일 파일 HTML embedded CSS와 repo-local link만 사용해 읽기용 문서로 둔다.

조건부 허용

항목 기준
raw HTML 꼭 필요할 때만 별도 parser로 읽고 allowlist sanitizer를 마지막 unsafe transform 이후에 적용한다.
도표 원문에 실제 흐름, 관계, 계층이 있을 때만 만들고 장식으로 추가하지 않는다.

금지

항목 기준
실행/외부 의존 <button>, inline JavaScript, event handler, javascript: link, vbscript: link, <iframe>, <object>, <embed>, 외부 CDN, 외부 script, 외부 image.
본문 자기해설 배치 의도, 색상 설명, 사용법 설명처럼 원문 의미가 아닌 문장을 넣지 않는다.
