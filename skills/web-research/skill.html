요약

현재 사실, 출처 검증, 추천, 제품 비교, 법·규정, 기술 문서를 source-first로 조사한다.

  • 사용할 때현재 사실, 출처 검증, 추천, 제품 비교, 법·규정, 기술 문서를 source-first로 조사한다.
  • 주요 입력조사 질문, 제공된 로컬 자료, 필요한 최신성, 출처 우선순위, research budget.
  • 주요 출력citation이 포함된 조사 결과, 출처 비교, 불확실성, 적용 가능한 결론.
  • 먼저 판단바뀔 수 있는 정보는 검색하고, 공식/원문 출처를 우선하며, 약한 근거는 약하다고 표시한다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.

사용 판단

이 화면은 스킬을 설치하거나 적용하기 전에 “언제 쓰고 무엇을 확인해야 하는지”를 빠르게 보여준다.

중요한 기준

  • 질문의 현재성 위험과 stakes를 판단한다질문의 현재성 위험과 stakes를 판단한다.
  • 스킬 자체 검토는 browse 요청이 아니다스킬 자체를 검토, 수정, 평가하라는 요청은 웹 검색 요청으로 해석하지 않는다.
  • 로컬 자료를 먼저 본다사용자가 제공한 파일, transcript, raw note, source note는 primary source로 삼고 웹 검색은 보강 근거로만 쓴다.
  • 가장 작은 충분한 research budget을 고른다단일 official quick check로 충분하면 거기서 멈추고, 넓은 검증이 필요할 때만 병렬 lane을 고려한다.
  • 추천, 비교, 구현 계획, skill update, PR, architect추천, 비교, 구현 계획, skill update, PR, architecture note, product decision의 입력으로 쓰이는 조사는 한 official source가 완전히 끝내지 않는 한 verified search로 분류한다.
