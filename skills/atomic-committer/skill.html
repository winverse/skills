atomic-committer

dirty git tree를 의미 단위로 나누고, 비밀값 guard를 통과한 changeset만 commit한 뒤 push 금지가 없으면 현재 branch를 한 번 push한다.

호출commit, 커밋, atomic commit
기본값commit + push
원본SKILL.md
검증validate-atomic-committer.ts

이 화면은 PC desktop 기준의 사람용 가이드다. 전역 설치나 repo 밖 변경은 하지 않는다.

커밋 출하 판단판

mode를 바꾸면 push 기본값, 차단 경계, 최종 보고 항목이 함께 바뀐다.

commit 요청 local only secret 발견 remote 누락
진행 commit 요청은 commit + push로 해석

push 금지 문구가 없으면 changeset별 commit 후 현재 branch를 한 번 push한다.

현재 mode의 보고 항목

commit hash, message, validation, push 결과, remote/branch를 최종 보고에 남긴다.

계약 1
의미 단위 분리

모든 변경을 한 번에 묶지 않고 logical changeset별로 commit한다.

계약 2
push 기본값

commit 요청은 기본적으로 commit + push 요청이다.

계약 3
secret 전후 검사

candidate diff와 staged diff를 모두 검사한다.

계약 4
hard-block

live-looking credential과 private key material은 commit을 멈춘다.

계약 5
완료 보고

push 실행, 생략, 불가 사유를 branch 정보와 함께 남긴다.

사용 판단

commit 요청의 기본값과 예외를 먼저 가른다. 넓은 표는 단독 영역에 둔다.

실행 흐름

화살표는 실제 node에 닿으며, guard는 commit 전과 staged 후 두 번 지나간다.

명령 순서

SKILL.md workflow를 사람이 확인하기 쉬운 실행 순서로 압축했다.

git rev-parse --show-toplevel
git status --short
git diff --stat
git diff
# guard: candidate diff + untracked files
git add <logical changeset files>
git diff --cached
# guard: staged diff
<validator/test>
git commit -m "docs: 한글 요약"
git push <remote> <branch> # push 금지가 없을 때

금지 내용 guard

이 guard는 경고가 아니라 hard-block이다. 허용 가능한 placeholder도 먼저 확인한다.

live-looking assignmentOPENAI_API_KEY, ANTHROPIC_API_KEY, GITHUB_TOKEN, DATABASE_URL, MONGODB_URI 등에 실제처럼 보이는 값이 있으면 중단한다.
private key material-----BEGIN PRIVATE KEY-----, -----BEGIN OPENSSH PRIVATE KEY-----는 commit 대상이 될 수 없다.
credential stringusername:password@ 형태 connection string과 AKIA..., ASIA... AWS key는 차단한다.
narrow ignore반복 생성되는 local artifact나 secret-bearing untracked file은 가장 좁은 .gitignore rule로 예방한다.
tracked secret이미 tracked된 secret은 .gitignore로 우회하지 않는다. 별도 제거와 기록 정리가 필요하다.
dummy 허용 후보placeholder, example, dummy, fake, redacted 값은 먼저 확인한 뒤 허용될 수 있다.
scope guardforce-push, tag, release, deploy는 사용자가 별도로 명시하지 않으면 하지 않는다.
message guardfeat, fix, docs 같은 English conventional prefix와 Korean summary를 쓴다.

파일 관계도

이 hook run은 인접 skill.html만 갱신한다.

SKILL.md커밋 분리, 기본 push, guard, final report의 원본 계약. skill.html현재 파일. 조작 가능한 판단판과 근거 연결을 제공한다. scripts/validate-atomic-committer.ts스킬 전용 문구와 구조 검증 후보. validate-skill-html.ts외부 자산, link, SVG arrow endpoint, 구조 검증.

메시지 형식

English conventional prefix와 Korean summary를 함께 쓴다.

docs: atomic-committer 시각 가이드 갱신
fix(secret-guard): private key 차단 조건 보강
chore(repo): 반복 생성 산출물 ignore 추가
권장 type
feat, fix, docs, refactor, test, chore, build, ci, style, perf, revert를 우선 사용한다. summary는 한국어로 짧게 쓴다.
