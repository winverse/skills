요약

dirty git tree를 secret guard로 확인한 뒤 logical changeset 단위로 commit하고 필요하면 push한다.

  • 사용할 때dirty git tree를 secret guard로 확인한 뒤 logical changeset 단위로 commit하고 필요하면 push한다.
  • 주요 입력현재 git 변경분, user intent, remote/branch 상태, secret scan 결과.
  • 주요 출력논리적으로 나뉜 commit, 한국어 요약을 포함한 conventional commit message, push 결과.
  • 먼저 판단비밀값처럼 보이는 내용은 hard block하고, unrelated dirty change는 되돌리지 않는다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.
