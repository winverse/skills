스킬 이름: skill-plugin-test-loop

스킬과 플러그인을 실제 cycle로 검증한다

fresh clone, isolated copy, 실제 첫 응답, cycle-NNN 산출물, failure class를 묶어 스킬이나 플러그인이 정말 기대대로 작동하는지 반복 확인한다.

호출 조건 스킬, 플러그인, plugin-bundled skill의 실제 동작을 확인할 때 쓴다.
반드시 하는 일 fresh clone 또는 isolated copy에서 실제 호출 기록과 산출물을 남긴다.
절대 하지 않는 일 기대 결과를 history에 끼워 맞추지 않는다.
완료 기준 실패 분류, 수정, 검증 명령, 다음 cycle 여부가 명확해야 한다.

사용 판단

스킬을 실제 prompt로 부르고 첫 응답, 질문 흐름, 생성 파일, validator 결과를 cycle history에 남긴다.

금지

로컬 작업본 몰래 사용

fresh clone 검증이 목표라면 local symlink나 global install에 기대지 않는다.

허용

fallback 기록

현재 runtime이 원본 command를 못 부르면 callable surface 누락을 기록한다.
