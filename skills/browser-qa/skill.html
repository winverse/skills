요약

웹 페이지나 skill.html을 브라우저에서 열어 console, network, 접근성, overflow, screenshot 증거로 검증한다.

  • 사용할 때웹 페이지나 skill.html을 브라우저에서 열어 console, network, 접근성, overflow, screenshot 증거로 검증한다.
  • 주요 입력localhost/file target, 사용자 시나리오, expected behavior, 시각 확인 요청.
  • 주요 출력브라우저 관찰 결과, screenshot/snapshot 증거, console/network 문제, 수정 필요 지점.
  • 먼저 판단실제 화면 증거를 기준으로 판단하고, destructive live action이나 secret 입력은 피한다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.
