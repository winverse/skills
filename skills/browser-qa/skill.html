browser-qa

실제 브라우저에서 관찰한 증거로 웹 화면, skill.html, console, network, accessibility snapshot, screenshot 문제를 확인한다.

입력URL, local file, viewport, 확인할 상호작용
출력PASS/FAIL, 관찰 근거, 증거 파일, cleanup 상태
원본SKILL.md
검증scripts/validate-browser-qa.ts
사용 판단

브라우저 증거가 필요한 요청에 사용한다.

렌더링, responsive layout, text overflow, broken link, console/network, accessibility snapshot, screenshot 확인이 대상이다.

범위

요청과 직접 관련된 상호작용만 수행한다.

주관적 디자인 평가는 design-review가 함께 요청된 경우에만 다룬다.

증거

관찰 없는 단정은 하지 않는다.

snapshot, screenshot, console, network 결과를 요약하고 파일 증거는 .artifacts/ 아래에 둔다.

정리

QA 뒤에 열린 tab과 직접 시작한 server를 정리한다.

사용자가 유지 요청을 하지 않았다면 Playwright/Chrome tab을 닫고, 시작한 local HTTP/dev server를 중지한다.

사용 판단

브라우저에서 확인해야 하는 화면 품질과 런타임 신호가 있을 때 이 스킬을 고른다.

사용 웹 페이지, web app, skill.html, responsive layout, console/network, accessibility snapshot, screenshot, broken link, text overflow 확인.
결합 시각 판단은 design-review, 문서 drift는 sync-docs, 구현 수정은 해당 작업 스킬과 함께 사용한다.
보류 대상 URL, local file, viewport, 확인할 사용자 흐름이 불명확하면 먼저 범위를 좁힌다.
차단 secret, payment data, destructive live action, 실제 서비스 상태 변경 버튼은 사용자 확인 없이 다루지 않는다.

작업 흐름

대상 URL 또는 local file을 열고 desktop과 필요한 mobile viewport를 정한다.
accessibility snapshot으로 구조와 주요 text를 확인한다.
console error와 network failure를 확인한다.
screenshot으로 overflow, overlap, blank canvas, missing asset을 본다.
관련 interaction만 수행하고 증거 저장 위치와 cleanup 상태를 보고한다.

금지와 허용

경계 규칙 실패 신호 대응
민감 입력 secret, payment data를 입력하지 않는다. 테스트 중 실제 민감값 입력 요청. 중단하고 더미 데이터 또는 별도 승인 범위를 요청한다.
상태 변경 실제 서비스에서 상태를 바꾸는 버튼은 사용자 확인 없이 누르지 않는다. 삭제, 결제, 전송, publish, submit 같은 live action. 관찰까지만 하고 클릭은 보류한다.
증거 위치 파일 증거는 .artifacts/browser-qa/ 또는 .artifacts/playwright/ 아래에 둔다. repo 루트의 snapshot*.png, *-desktop.png, test-results/. 새 기준 위치로 저장하고 보고에 경로를 적는다.
정리 완료 뒤 QA용 browser tab과 직접 시작한 server를 방치하지 않는다. 열린 session이나 background server가 남음. 닫거나 중지하고, 유지해야 하면 사유를 남긴다.

출력 형식

최종 보고는 확인 범위, PASS/FAIL, 증거, cleanup을 짧게 남긴다.

확인 범위
- <URL/file/viewports>

결과
- PASS/FAIL: <관찰 근거>

증거
- console: <요약>
- screenshot/snapshot: <.artifacts/browser-qa/... 파일 또는 관찰>
- cleanup: <닫은 browser/session, 중지한 server, 또는 유지 사유>

파일 관계와 검증

원본 지시 skills/browser-qa/SKILL.md 에이전트가 따르는 browser QA 계약.
참조 기준 references/browser-checklist.md 세부 점검 기준이 필요할 때 읽는 보조 문서.
스킬 검증 node scripts/validate-skill.ts skills/browser-qa 스킬 폴더 기본 구조와 frontmatter를 확인한다.
전용 검증 node skills/browser-qa/scripts/validate-browser-qa.ts skills/browser-qa browser QA 문구, 증거 위치, cleanup 규칙을 확인한다.
HTML 검증 node scripts/validate-skill-html.ts . 외부 자산, 위험한 링크, local link, layout 기준을 확인한다.

완료 기준

10초 안에 입력, 출력, 보존할 증거, 차단할 행동, 실행할 검증 명령이 보여야 한다. 이 문서는 script 없는 정적 HTML이며 외부 asset을 사용하지 않는다.
