사용

code review, PR review, diff review, implementation audit, regression risk, missing test, maintainability, JS/TS style, agent/tool-call bou...

결합

문서 drift는 sync-docs, 브라우저 증거는 browser-qa, 커밋은 atomic-committer와 연결합니다.

보류

호출 조건이 애매하거나 대상 repo 경계가 불명확하면 먼저 근거 파일을 읽고 범위를 좁힙니다.

차단

전역 설치, 파괴적 명령, 승인 없는 publish, 비밀값 노출은 이 스킬 작업에 섞지 않습니다.

작업 흐름도

화살표는 실제 상자에 닿고, 각 단계는 검증 가능한 출력으로 이어집니다.

1. review stance 기준bug, behavioral regression, missing test, security risk를 우선한다.
2. review stance 기준추측은 추측이라고 표시한다.
3. review stance 기준문제가 없으면 그렇게 말하고 residual risk나 test gap만 남긴다.
4. output shape 기준[severity] path:line - 문제와 영향

SKILL.md에이전트가 읽는 원본 지시입니다. skill.html사람이 빠르게 검토하는 인접 시각 가이드입니다. scripts/validate-code-review.ts스킬 전용 검증기입니다. references/js-ts-style.md긴 기준과 세부 근거를 담는 참조 문서입니다. references/review-checklist.md긴 기준과 세부 근거를 담는 참조 문서입니다. ../../project-snippets/code-review.md프로젝트 instruction에 연결하는 사용 조각입니다. ../../scripts/validate-skill-html.ts공통 HTML 구조와 SVG arrow endpoint를 확인합니다.

금지와 허용

misuse guardrails는 스킬이 맡지 않는 일을 명확히 분리합니다.

허용

대상 repo 안에서 관련 파일을 읽고, 요청된 행동을 스킬 계약대로 수행합니다.

허용

검증 가능한 산출물, 짧은 근거 보고, 필요한 validator 실행 결과를 남깁니다.

보류

호출 조건 밖 refactor, repo-wide preference 변경, 대상 밖 문서 확장은 별도 요청으로 분리합니다.

금지

전역 설치, 비밀값 노출, destructive command, 승인 없는 commit/push/deploy는 진행하지 않습니다.
