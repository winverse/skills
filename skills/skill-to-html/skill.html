원본, 사람용 화면, 기준, 검증기를 한 장면으로 연결합니다.

SKILL.md핵심 계약과 생성 workflow입니다. visual-guide-standards.md상호작용, 애니메이션, 도표 무결성, 닫힌 파일 기준입니다. validate-skill-to-html.ts그림 먼저, 인터랙티브, 애니메이션 문구를 검사합니다.

금지와 허용

상호작용은 허용하되 외부 의존은 닫습니다.

허용CSS/SVG animation, Web Animations API, 짧은 inline JavaScript.
허용PC desktop의 click, hover, focus, keyboard state 확인.
금지외부 CDN, 외부 script, 외부 image, network call.
금지의미 없는 장식 animation, 긴 설명 카드로 첫 화면 채우기.

프로젝트 연결 조각

프로젝트 instruction에는 호출 조건과 완료 기준만 둡니다.

Use $skill-to-html at skills/skill-to-html/SKILL.md when a skill is created or materially updated.
Treat SKILL.md as the source of truth and skill.html as a visual view.
Read Markdown meaning, extract skill IR, map to visual components, then render standalone HTML.
Start skill.html with a visual, interactive, animated first viewport before long text.
Use self-contained CSS/SVG/Web Animations API or short inline JavaScript; no external CDN/script/image.
Do not pass Markdown raw HTML, event handlers, javascript: links, or external scripts through.
Validate with node scripts/validate-skill-html.ts . and the target skill's validator.
