skill-to-html

SKILL.md를 사람이 빠르게 확인하는 정적 요약 skill.html로 압축한다. Markdown을 그대로 붙이지 않고, 작은 중간 모델과 신뢰된 템플릿으로 안전하게 렌더링한다.

정적 요약 한국어 우선 인터랙션 없음 신뢰 경계

요약

SKILL.md에서 필요한 의미만 뽑아 SkillHtmlModel로 줄이고, 신뢰된 템플릿으로 짧은 정적 skill.html을 만든다.

  • 입력Markdown은 신뢰하지 않는 입력으로 읽는다.
  • 출력같은 폴더의 단일 HTML만 갱신한다.
  • 차단raw HTML, event handler, 위험한 URL 속성, 외부 script는 통과시키지 않는다.

사용 판단

스킬이 새로 만들어졌거나 계약이 바뀌었고, 사람이 설치 전후에 빠르게 볼 화면이 필요할 때 사용한다. 단순 오탈자 수정이나 이미 최신인 HTML에는 쓰지 않는다.

핵심 계약

  • 기준 원문 유지skill.html은 SKILL.md를 대체하지 않는다.
  • 중간 모델 사용원문을 바로 렌더링하지 않고 SkillHtmlModel로 압축한다.
  • 한국어 우선화면에 보이는 일반 설명어는 한국어로 번역한다.
  • 정적 화면버튼, script, animation, 보기 전환 없이 읽힌다.
  • 짧은 요약세부 예시와 긴 절차는 원문 링크로 넘긴다.

작업 흐름

  1. 1원문 읽기Markdown을 신뢰하지 않는 입력으로 보고 의미만 읽는다.
  2. 2모델 추출SkillHtmlModel에 호출 조건, 계약, 금지 경계만 담는다.
  3. 3HTML 작성신뢰된 템플릿으로 정적 section을 배치한다.
  4. 4확인넘침, 겹침, 링크, 위험한 URL 속성을 확인한다.

금지와 허용

허용 정적 CSS, 로컬 링크, 전체 폭 표, 짧은 코드 경로, 정확한 식별자, 신뢰된 템플릿.
금지 <button>, inline JavaScript, event handler, javascript: link, vbscript: link, <iframe>, <object>, <embed>, 외부 CDN, 외부 script, 외부 image.

파일과 검증

파일 관계는 SKILL.md가 기준 원문이고, skill.html은 사람용 요약 화면이다. 세부 기준은 visual-guide-standards.md와 validate-skill-to-html.ts에서 확인한다.

  • 전용 검증정적 요약, 한국어 우선, SkillHtmlModel, 신뢰 경계를 확인한다.
    node skills/skill-to-html/scripts/validate-skill-to-html.ts skills/skill-to-html
  • 브라우저 검증PC desktop에서 script/button 부재와 넘침을 확인한다.
    node skills/skill-to-html/scripts/validate-skill-to-html-render.ts skills/skill-to-html
