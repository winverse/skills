요약

남은 token/context budget을 안전하게 써서 스킬 호출성, validator, 문서 정합성, eval 품질을 개선한다.

  • 사용할 때남은 token/context budget을 안전하게 써서 스킬 호출성, validator, 문서 정합성, eval 품질을 개선한다.
  • 주요 입력사용자가 허용한 남은 budget, 현재 repo 상태, backlog 후보, 검증 실패나 반복 불편.
  • 주요 출력작은 품질 개선 patch, validator/eval/docs 보강, 안전한 backlog 처리 결과.
  • 먼저 판단사용자 확인 없이 spend-down을 시작하지 않고, durable artifact가 남는 작업을 우선한다.
  • 검증관련 validator와 node scripts/validate-skill-html.ts .로 확인한다.
