AI Video Workflow

동의된 Voicebox 목소리 profile과 HyperFrames HTML 영상 제작을 연결해 대본, 나레이션, 모션 그래픽 brief, render 검증까지 한 흐름으로 관리하는 plugin-bundled skill이다.

요약

입력 대본, 영상 목적, 목소리 profile, 화면 비율
출력 나레이션 brief, HyperFrames brief, 검증 기록
도구 Voicebox, HyperFrames, FFmpeg, Node 22
경계 동의 없는 목소리 복제 금지

목소리 샘플

본인 목소리 샘플을 쓰는 방식은 적합하다. 다만 샘플 파일은 shared repo에 넣지 않고 target project의 ignored private path나 Voicebox profile 내부에만 둔다.

사용 판단

사용 건너뜀
대본을 본인 목소리 나레이션과 정보형 모션 그래픽 영상으로 만들 때 타인의 목소리를 동의 없이 복제하려는 요청일 때
Voicebox profile, private voice sample, HyperFrames render가 함께 필요할 때 실사 cinematic video generation 자체가 목표일 때
오디오, HTML source, MP4 산출물 검증을 한 번에 남겨야 할 때 이미 완성된 영상의 일반 UI/디자인 리뷰만 필요할 때

작업 흐름

1. 입력목적, 대상, 길이, 비율, 대본 상태를 정리한다.
2. 동의목소리 소유자와 사용 범위를 확인한다.
3. 점검doctor.ts로 Node, FFmpeg, Voicebox 상태를 본다.
4. 생성scaffold-video-project.ts로 영상 프로젝트를 만든다.
5. 음성Voicebox profile로 짧은 테스트 뒤 전체 나레이션을 만든다.
6. 영상HyperFrames brief를 채우고 preview/render로 넘긴다.
7. 검증audio, HTML source, MP4, caption timing을 확인한다.

보안 경계

허용

  • 본인 목소리 또는 명시적 동의가 있는 목소리 profile 사용
  • target project의 ignored private path에 샘플 보관
  • Voicebox localhost tool 사용 전 risk gate 기록
  • 생성 음성과 영상 산출물의 출처 기록

금지

  • 동의 없는 타인 목소리 복제
  • shared repo에 실제 voice sample commit
  • Voicebox profile silent fallback에 의존
  • Voicebox MCP를 plugin manifest에 자동 등록해 시작 경고를 만드는 구성

파일과 검증

node plugins/ai-video-workflow/scripts/doctor.ts
node plugins/ai-video-workflow/scripts/scaffold-video-project.ts /path/to/video-project --title "sleep-cycle-short" --profile "My Voice"
node plugins/ai-video-workflow/scripts/validate-video-project.ts /path/to/video-project
파일 역할
SKILL.md 에이전트가 따르는 제작 workflow와 안전 기준
references/source-ledger.md Voicebox, Voicebox MCP, HyperFrames 확인 출처와 local 채택 판단
scripts/doctor.ts 로컬 도구와 Voicebox port 준비 상태 확인
scripts/scaffold-video-project.ts 대본, 나레이션, 영상 brief, private asset 경계 생성
scripts/validate-video-project.ts 프로젝트 구조와 선택 산출물 존재 검증
