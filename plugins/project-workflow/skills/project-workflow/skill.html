중요한 기준

  • 실제 호출 상태호출됨(invoked)은 해당 skill/plugin/command를 실제로 호출했거나, 현재 runtime의 명시적 호출 경로로 넘긴 상태다.
  • 보류 상태보류(deferred)는 도메인, 제품, 디자인, 도구 게이트 답변 뒤에 실행해야 하므로 지금은 미루는 상태다.
  • 출처가 있는 primitiveMatt Pocock skills의 setup-matt-pocock-skills, grill-with-docs, to-prd, to-issues, triage는 출처와 채택 역할을 함께 기록한다.
  • 도메인 구조 gate중간 이상 규모나 장기 유지 프로젝트는 DDD-lite structure gate로 bounded context, domain invariant, domain-first folder map, folder-local instruction docs, TDD 시작 후보를 남긴다.
  • 화면 작업큰 UI 작업이면 design.md와 2-3개 시안 방향을 보류로 표시하고, 도메인/제품 답변 뒤에 요청한다.
  • 호출 경로 확인repo-local skill, enabled plugin, slash command, MCP/tool, agent-specific workflow surface 순서로 실제 호출 가능성을 확인한다.

  4. 4화면 작업 기준 확인UI 작업이면 design.md 또는 선택한 시안 방향이 있다.
  5. 5TypeScript 모듈 기준 고정TypeScript 작업이면 ESM only, type: "module", import/export, CommonJS 금지 제약이 CONTEXT.md, ADR, PRD, 이슈, 또는 workflow-state.md 중 하나에 남아 있다.
  6. 6도구/보안 위험 판단도구, API, MCP 작업이면 도구/보안 위험 게이트(Agent Tool And Security Risk Gate) 결정이 있다.
